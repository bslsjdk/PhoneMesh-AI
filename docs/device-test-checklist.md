# First real-device test checklist

Use only phones you control. Do not expose the benchmark server to public or untrusted networks.

## Before testing

- [ ] Both phones have Wi-Fi enabled; mobile data and internet access are not required.
- [ ] Keep both phones cool and remove heavy cases if they heat up.
- [ ] Install the same debug APK on both devices.
- [ ] Grant Nearby devices permission. On Android 12 and older, grant Location permission and enable Location if peer discovery asks for it.
- [ ] Keep the app visible during the first test to avoid background execution limits.
- [ ] Do not start model inference yet.

## Connect

1. Open PhoneMesh on both phones.
2. Tap **Scan nearby phones** on each phone.
3. Select the other phone in the list and tap **Connect to selected phone**.
4. Accept Android's system pairing/connection prompt if one appears.
5. Wait until both screens report a group connection and show the group-owner address.
6. On the group-owner device, tap **Start benchmark server** and wait for the explicit “server is listening” message.
7. On the client device, tap **Send 16 MiB benchmark**.
8. Record both client and server rate values, any error text, and whether either phone gets noticeably warm.
9. Repeat three times. Let the phones cool between sustained tests if needed.

## What the current benchmark does

- Transfers 16 MiB of generated bytes, using a 64 KiB reusable buffer.
- Does not store the whole payload in memory.
- Reports client elapsed time and the server's measured payload rate.
- Limits incoming benchmark payloads to 64 MiB.

The first prototype tests one direction only. A later version should add reverse-direction tests, small-message RTT/p95 measurements, multiple payload sizes, checksums, and thermal observations.

## Report results

For each run, write down:

- Phone acting as group owner and phone acting as client.
- Connection setup time.
- Client rate and server payload rate in Mbit/s.
- Errors or disconnects.
- Approximate temperature/battery behavior before and after.
- Android version on each phone.

Do not interpret the Wi-Fi transfer rate as tokens per second. Model inference has additional compute, serialization, synchronization, and memory costs.
